# Emit a YAML list under a key

Emit a YAML list under a key

## Usage

``` r
yaml_list(key, items, n = 2L)
```

## Arguments

- key:

  String. The key.

- items:

  Character vector. The list items, already formatted.

- n:

  Integer. Indent of the key in spaces.

## Value

Character vector of YAML lines.
