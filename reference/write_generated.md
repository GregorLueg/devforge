# Write rendered sources, format them and prepend the generated header

air skips any file whose first line reads "Generated by", so the header
goes on after formatting, not before.

## Usage

``` r
write_generated(rendered, paths)
```

## Arguments

- rendered:

  Named list of character vectors, as from
  [`render_specs()`](https://gregorlueg.github.io/devforge/reference/render_specs.md).

- paths:

  Character vector of file paths, one per entry of `rendered`.

## Value

`paths`, invisibly.
