# Boolean field

Boolean field

## Usage

``` r
p_lgl(default, null_ok = FALSE, doc = NULL)
```

## Arguments

- default:

  Boolean or `NULL`. The default value.

- null_ok:

  Boolean. Whether `NULL` is permitted. Defaults to `FALSE`.

- doc:

  String or `NULL`. Roxygen prose for this field.

## Value

A `devforge_field`.
